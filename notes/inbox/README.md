# Inbox

Notes from AI conversations that could not write to the repo (chat-only ChatGPT, Claude.ai without the repo, phone apps).

- The owner saves the note the AI produced here as `YYYY-MM-DD_<ai>_<topic>.md` (GitHub web upload or commit is fine).
- The next repo-capable agent merges each note into the right places (Decision Log, Test Log, Hardware as bought, Start Here notes, HANDOFF), then deletes the inbox file in the same commit and says so in its session note.
- Template: `notes/templates/Inbox_Note_Template.md`.
