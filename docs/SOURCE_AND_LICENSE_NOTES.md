# Source provenance and permissions

Original source meshes are third-party-style character/prop designs. Their creator, license and redistribution terms have not been verified. This repository must remain private until those terms are established. Do not add an open-source license for the original models or claim rights in the *Arcane* franchise.

Preserve original model files unmodified under `originals/`; put redesigns in versioned releases. Record sources, licenses, and modifications when verified.
