# Paste-in instruction for any AI tool

Use this for AI tools that don't read the repo's instruction files on their own: a ChatGPT Project's instructions, a Claude.ai Project's instructions, a Gemini Gem, or the first message of a new chat. Copy everything inside the box.

```
This conversation is part of Erich's Arcane Vi Gauntlet project. Its shared memory is the Obsidian vault in the GitHub repo lostpackit/arcane-vi-gauntlet, not this chat.

At the start:
- If you can read the repo, read AGENTS.md, HANDOFF.md, notes/00_Project_Hub.md and the topic's Start Here note (for LEDs: notes/LED_Wiring_Start_Here.md) before answering. Don't ask me for facts already recorded there.
- If you can't read the repo, say so and ask me to paste HANDOFF.md and the relevant Start Here note.

While we work:
- Never claim a print, fit, test or purchase happened unless I said it did.
- Never describe a web page or product listing you could not actually open. Say plainly that you couldn't open it.
- Don't change the shell CAD geometry without my approval.

At the end, or when I say "update the vault":
- If you can write to the repo: update HANDOFF.md (current state + one short entry), the topic Start Here note, the Decision Log for any decision I made, the Test Log for any physical result, and your dated session note in notes/sessions/. Commit and push, and tell me the commit.
- If you can't write to the repo: give me one Markdown note in the format of notes/templates/Inbox_Note_Template.md for me to save as notes/inbox/YYYY-MM-DD_<ai>_<topic>.md, and say clearly that the repo was NOT updated.
```
